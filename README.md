# 黄金宝库之钥 · 霾都狂徒档案

从五人 D&D 跑团场记里抽出的可读剧本，以及给 GPT Image 2 用的角色身份卡与建模题词。

队伍：野蛮人肉肉、牧师米艾莉、游侠克洛斯、吟游诗人缇露、邪术师耀希。团名在群里叫「黄金宝库之钥」，主舞台是霾都阿肯斯塔。

## 本地运行

```bash
npm install
npm run dev -- --port 43147
```

打开 `http://127.0.0.1:43147`。

- `/scripts` 六场剧本
- `/characters` 五人 Image 2 身份卡
- `/download` 打包整站

## 打包成可带走的网页

不要用浏览器「另存为」，那样只会留下当前这一页。在仓库根目录：

```bash
npm run pack
```

会先静态导出全部页面，再压成 `dist/haze-city-archive.zip`。解压后运行「打开档案.sh」或「打开档案.bat」，浏览器打开 `http://127.0.0.1:8765`。不要直接双击 `index.html`。

同一份压缩包也会复制到 `public/haze-city-archive.zip`，档案站上的「打包下载」按钮指向它。

## Image 2 怎么用

每张角色页都有一段 Identity Card。先用「角色设定三视图」出锚点底图，之后每条题词都原样粘贴身份卡，并且只改 Change only 里的一个变量。

场记里没写死的外貌（发色、鳞色、圣徽形状等）在身份卡里做了锁定，并在页面上标明了哪些来自开团记录。
