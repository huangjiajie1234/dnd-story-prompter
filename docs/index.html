    蛋与霸王龙

    任务书上写的是「控制青足龙蛇之卵的影响范围」。他们最后把博物馆大门撞穿，骑着十几米高的问题走进夜色。

    金罐子的小姐

    耀希问储蓄流程，肉肉负责当保镖。两个人把「了解金库安全等级」演成了持枪抢劫。

    机魂，嫁给我吧

    豺狼人、发条猎犬、失踪的蒙西小姐，本该是清理任务。肉肉决定在战场上解决终身大事。

    酒厂里的戒指

    菲比摊牌自己在给女大公干活。下一单是把瓦申·盖特比从布满机关的家里救出来。半路停在酒厂，是因为有人要求婚。

  • 第五场前后 · 2026-06-30 / 07-06

    热步斗舞场

    线索指向一个失败学长：邵马·利泽留斯。要见爆桶朋克，得先从几十人的斗殴里活着出来。

  • 后半段 · 2026-07-20 至 08-17

    二度之吻号

    失踪的一级齿轮带走了爆熔雷的逆向配方。陆路等于自杀，所以他们去买一张不该这么贵的船票。
