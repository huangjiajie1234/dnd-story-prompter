第五场前后 · 2026-06-30 / 07-06

热步斗舞场

查一个人名，洗劫一家舞厅

天空城 · 长角酒廊 / 雾霾城 · 热步斗舞场 / 装置工厂旧仓库

线索指向一个失败学长：邵马·利泽留斯。要见爆桶朋克，得先从几十人的斗殴里活着出来。

莱卡试剂讲了火元素血脉烧光头发的退学传闻。长角酒廊只认会员证和牛仔证——贵族背景的耀希带着侍从走进去。热步斗舞场里有人在跳霹雳舞，有人在甩杀马特。

一、三处地名

枪弹酒吧的常客们比盾勋执法官好说话。肉肉先去跟舞台剧演员聊天。

旁白

北边那位兽人枪手长着獠牙，却有魔鬼的角。她是魔裔半兽人赏金猎人，也是《正午雄心》里长牙警长的演员。

酒保

那些爆桶朋克？我听说他们一周前想闯入天空城的长角酒廊。他们带着一些有发条四肢的猴子。盾勋执法官把他们赶回了雾霾城。真是可喜可贺。

一村裕民

伙计，你看起来和埃尔沙普是朋友？你们都有猫的耳朵。

旁白

药店招牌是一只飞翔的乌鸦，爪子里抓着小液瓶——莱卡试剂。加上长角酒廊、热步斗舞场，三处位置齐了。

二、贵族负责 cue 流程

长角酒廊门卫拦住没有牛仔证的人。

门卫

站住，伙计们。长角酒廊只允许最富有奢华的客人进入，或者是牛仔竞技冠军。你们有会员证或者牛仔证吗？

旁白

耀希只要开口，贵族谈吐就够了。门卫放行，还可以带一个侍从。香薰、杂技、只有一小点的贵食。

克洛斯

我发现贵族负责 cue 流程，派任务，是项目经理。

缇露

弹个鲁特琴提供点 BGM，挂会机，等其他人问情报。

三、失败男人的火

莱卡张开乌鸦嘴打招呼，以为他们是布莱瑟学院新生。

传闻

邵马学长失败的原因其实是他体内火元素裔的血脉开始显现。退学那天，有人看到他的眼睛变成明亮的金色，身材变得很高大，皮肤变成焖烧泥土那样的棕色。他苍白的头发被活体火焰烧光并取代。

旁白

他和爆桶朋克在长角酒廊谈过计划。热步斗舞场是他们的地盘。

四、几十人的混战

硕大的舞台，刺耳的音乐，杀马特发型。雷鸣音波先把保安的耳朵掀了。

旁白

在刺耳的音乐和灯光之中，霾都的狂徒从一场几十人的斗殴大混战中活了下来，并且在盾勋执法官抓住他们之前逃了出去。同时把此处给洗劫了一空。

缇露

你再次演奏你的乐器。

〔雷鸣音波。要过来行凶的家伙痛苦倒地。〕

旁白

他们现在知道了爆桶朋克所在的装置工厂旧仓库。十年前这里做发条小家具，破产后只剩下手摇绞车和钢壳火柴。如今高台上有一座用烧毁发条碎片堆起来的精巧宝座。

五、咬咬

黄铜机械盔甲的地精从废品王座上站起来，揉了揉绿色眼睛周围的灰褐色皮毛。

地精领袖

我已经把几个欠钱不还的人喂给咬咬了，但看着他们被吃掉真的很无聊。另外，咬咬饭量太大了。如果你们杀了它，我就可以少一张吃饭的嘴了。你们如果把它带走，就证明它背叛了我。我在它还是一只小蛇的时候就养着它了。

耀希

你们先看看和蛇怎么聊？我让乌鸦看看精神小伙身上或者房间里有没有类似钥匙的东西。

旁白

一猫一兔悄咪咪翻到窗户旁边，小心翼翼把窗户推开，翻了进去。邵马雇的怪物后来靠心灵感应把盾勋执法官引了好长一段路。他们还是把那东西弄死了，甩掉了执法官。
