第二场 · 2026-06-01

金罐子的小姐

雾霾城里第一次正经踩点，以及一次不太正经的参观

阿肯斯塔 · 枪弹酒吧 / 金罐子储蓄银行

耀希问储蓄流程，肉肉负责当保镖。两个人把「了解金库安全等级」演成了持枪抢劫。

菲比在包厢里发活。目标是安布罗斯特·穆格兰洗黑钱用的金罐子银行。队伍先喝白兰地，有人把头发点着，然后走进了那家看起来很旧的银行。

一、枪弹酒吧的欢迎词

亚铁区一条低矮的两层建筑。招牌写着「枪弹酒吧，饮料－食物－防火客房」。女矮人从吧台上跳下来，把新来的狂徒带进包厢。

旁白

舞台上刚演完《正午雄心》的一折：兽人警长对矮人开了一枪，全场鼓掌，两人鞠躬去点威士忌。威士忌只卖两银币。

缇露

嘿！就是你看中我们，把我们大费周章舟车劳顿地喊过来的吗！真是有眼光喵！

缇露

那个谁又没说不能大闹一场！她不就是要把里面东西弄出来嘛！完美完成任务喵。有什么关系，看我胡须烧起来了，多帅啊喵。

肉肉

嘿，女矮人，我就觉得我现在就像你这家酒吧的太阳一样，可以帮你省下不少灯油钱！

耀希

上次抢博物馆这次抢银行，我们以后出去还做不做人了。

二、存钱吗，小姐

金罐子储蓄银行大堂。发条保安，旧神殿改的金库门。耀希走进去，肉肉跟在后面。

耀希

我是外地刚来的，想找个银行存点钱。你们这个银行外面看上去有点旧。安保行不行的，你给我介绍介绍你们的安保系统呢。只有两个保安太少了吧，盾勋执法官在哪里？万一停电了怎么办，你们的保安用的是电池吗。

肉肉

我走进银行跟到耀希身后。如果有人问起，我就说我是耀希的保镖。

肉肉

我们家小姐来这里旅游，听说这家银行是这里最大的银行，想存一笔钱。可刚刚看了眼这里的安全措施，好像不太行的样子啊？

肉肉

博德之门的银行都不敢瞒我们，你还商业机密？小姐，要不咱们还是另找其他的银行吧。哦对了，得跟穆格兰先生打声招呼。

耀希

你看我这个宝石够不够格存在你们银行。我需要详细了解下你们的金库存款流程，方不方便带我走一回。

三、行长办公室

红木雕花墙板，两株健康得过分的盆栽。女矮人行长刚还在喝茶玩纸牌。

行长

难道是布莱的牧师？！我的挪用公款被发现了？！

耀希

为了你的小命你最好不要问是谁派我们来的。能有这种宝石，你也没有几条命可以猜。你现在最好是好好听我们的，不然别想看见明天的太阳。

肉肉

直接让她带我们进金库，然后把她的证据全都拿捏住，这样她不会反水。

米艾莉

给她把外伤治愈一下，这样看不出来刚被揍了一顿。

缇露

我先地上弄点杂草，然后跳到旁边房顶点个小火，让火慢慢烧。我能不能对着着火的院子防一个妖火，把火染成绿的。

四、后院火场

计划里的「了解安全措施」已经没人记得了。克洛斯的兔子跳在火焰里仍然有优势。

米艾莉

如果动静小点，我开沉默还来得及隔绝声音吗。

米艾莉

但他们的首领似乎没有罢休。我们一边跑一边说？

克洛斯

我们等会去上交任务应该就能换点新的了。

旁白

菲比后来把这些事记进小本本：持枪抢劫、暴力抗法、逃脱法律制裁。相当多的黑料。她笑着说，从一开始她就不仅仅是个开酒吧的。
